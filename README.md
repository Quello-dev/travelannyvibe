# TravelAnyVibe — маршрут под ваш вайб (версия на Python)

Мобильное приложение-гид (интерактивная веб-презентация). Человек описывает поездку своими словами,
приложение уточняет детали (до 5 вопросов), DeepSeek выбирает один лучший город,
а маршрут по часам собирается из проверенной базы мест. Проект колледжа «ИТ.Москва».

Вся логика написана на **Python** (фреймворк Flask). Браузер только показывает готовые
страницы: HTML-шаблоны и CSS-стили.

## Запуск

Нужен Python 3.10 или новее. На Mac команды пишутся с `python3`, на Windows — с `python`.

1. Откройте терминал в папке проекта и установите Flask: `python3 -m pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и впишите свой ключ Zveno в строку `AI_KEY=`.
3. Запустите: `python3 app.py` — сайт сам откроется в браузере.
4. Если не открылся — скопируйте адрес, который появился в терминале (обычно http://127.0.0.1:8000).

## Как это работает

1. **Запрос своими словами** — пожелания («С детьми», «В дождь»…) и число дней распознаются из текста.
2. **Уточняющие вопросы** — задаются только те, ответа на которые ещё нет в запросе.
3. **Лучшее совпадение** — DeepSeek выбирает один город из 6 и объясняет почему.
4. **Маршрут по часам** — RAG-поиск ранжирует места из базы, планировщик расставляет их по слотам дня,
   DeepSeek определяет адреса и считает время в пути на машине.

## Структура проекта

```
TravelAnyVibe-py/
├── app.py                 # сервер Flask: адреса экранов и переходы между ними
├── requirements.txt       # нужные библиотеки (только Flask)
├── .env.example           # шаблон настроек с ключом (сам .env никому не отправляйте)
├── data/
│   ├── cities.py          # справочник городов и их цвета
│   └── places.py          # база мест: 122 места в 6 городах
├── travel/
│   ├── text.py            # работа с текстом запроса
│   ├── wishes.py          # распознавание пожеланий и количества дней
│   ├── questions.py       # уточняющие вопросы
│   ├── rag.py             # RAG: поиск и ранжирование мест
│   ├── planner.py         # сборка маршрута по часам
│   ├── ai.py              # запросы к DeepSeek через Zveno
│   └── assets.py          # рисунки городов, логотип, значки
├── templates/             # HTML-шаблоны пяти экранов (Jinja)
└── static/styles/         # CSS-стили
```

## Кто за что отвечает

| Участник | Роль | Файлы |
|---|---|---|
| **Лиза** | тимлид, приложение, дизайн | `app.py`, `travel/planner.py`, `travel/wishes.py`, `travel/text.py`, `travel/assets.py`, `templates/`, `static/`, `data/cities.py` |
| **Антон** | RAG-система | `travel/rag.py` |
| **Андрей** | база данных, ИИ-диалог | `data/places.py`, `travel/ai.py`, `travel/questions.py` |

## Безопасность ключа

Ключ хранится только в `.env` на сервере и в браузер не попадает: к DeepSeek обращается Python-код
(`travel/ai.py`). Файл `.env` исключён из git (`.gitignore`).
